Configure Responsible AI safety settings¶

Caution: Starting on June 24, 2025, Imagen versions 1 and 2 are deprecated. Imagen models imagegeneration@002, imagegeneration@005, and imagegeneration@006 will be removed on September 24, 2025 . For more information about migrating to Imagen 3, see Migrate to Imagen 3.

Try image generation (Vertex AI Studio) Try Imagen in a Colab

This page describes how to configure Responsible AI (RAI) safety filters for image generation with Imagen on Vertex AI.

You can use several RAI filtering parameters to control model behavior. For example, you can get detailed reason codes for blocked content, disable people or face generation, adjust the sensitivity of content filtering, or receive RAI scores for safety attributes in the model's input and output.

The available settings depend on the Imagen model version you use. For more information, see Imagen models and the API reference. For a deeper understanding of RAI, see Responsible AI and usage guidelines for Imagen.

Before you begin¶

Concepts
  • Responsible AI (RAI): A framework of tools and practices to help ensure AI systems are developed and used ethically and safely.
  • Imagen: Google's family of text-to-image diffusion models for generating photorealistic images from natural language prompts.
  • Text Prompt: A short text description that you provide to a generative model to guide its output, such as generating an image.

Ways to configure safety settings¶

You can configure safety settings using either the Google Cloud console for a visual, interactive experience or the REST API for programmatic control and integration.

Method Description Best for
Google Cloud console A graphical user interface (GUI) in Vertex AI Studio for interactively generating images and adjusting safety settings. Quick experiments, visual feedback, and users who prefer a no-code environment.
REST API A programmatic interface for sending requests to the Imagen model and receiving generated images. Integrating image generation into applications, automating workflows, and accessing advanced safety controls.

Configure safety settings¶

Choose one of the following methods to configure RAI safety settings for Imagen.

This section shows you how to configure safety settings using the image generation workflow in the Vertex AI Studio.

Configure safety settings in the Google Cloud console

1. Go to Media Studio

In the Google Cloud console, go to the Vertex AI > Media Studio page.

Go to Media Studio

2. Select Imagen

Click Imagen. The Imagen Media Studio image generation page is displayed.

3. Adjust model settings

In the Settings panel, adjust the following options:

  • Model: Choose a model from the available options. For more information, see Imagen models.
  • Number of results: Adjust the slider or enter a value between 1 and 4.

4. Configure safety settings

In the Safety section, configure the following settings:

  • Select one of the following Person generation settings:
    • Allow (Adults only): Generate adult people or faces only. Does not generate youth or children.
    • Allow (All ages): Generate people or faces of all ages.
    • Don't allow: Don't generate people or faces.
  • Select one of the following Safety filter threshold settings:
    • Block most: Blocks the most potentially harmful content.
    • Block some: Blocks some potentially harmful prompts and responses.
    • Block few: Blocks only the most clearly harmful prompts and responses.

5. Write a prompt

In the Write your prompt box, enter a text prompt that describes the image to generate. For example, a small boat on the water in a morning watercolor illustration.

6. Generate images

Click send Generate.

Before using any of the request data, make the following replacements:

  • PROJECT_ID: Your Google Cloud project ID.
  • LOCATION: Your project's region. For example, us-central1, europe-west2, or asia-northeast3. For a list of available regions, see Generative AI on Vertex AI locations.
  • TEXT_PROMPT: The text prompt that guides what images the model generates.
  • IMAGE_COUNT: The number of generated images. Accepted integer values: 1-8 (imagegeneration@002), 1-4 (all other model versions). Default value: 4.
  • SAFETY_SETTING: Optional. A setting that controls safety filter thresholds. Available values:
    • block_low_and_above: The highest safety threshold, filtering the largest amount of content.
    • block_medium_and_above (default): A medium safety threshold that balances safety and content availability.
    • block_only_high: The lowest safety threshold, filtering the least amount of content.
  • PERSON_SETTING: Optional. The safety setting that controls people or face generation. Available values:
    • allow_adult (default): Allows generation of adults only. Celebrity generation is not allowed.
    • dont_allow: Disables the inclusion of people or faces in generated images.
  • INCLUDE_RAI_REASON: Optional, boolean. Whether to include the Responsible AI filtered reason code in responses with blocked content. Default: true.
  • INCLUDE_SAFETY_ATTRIBUTES: Optional, boolean. Whether to include rounded Responsible AI scores for safety attributes in responses for unfiltered content. Safety attribute categories include "Death, Harm & Tragedy", "Firearms & Weapons", "Hate", "Health", "Illicit Drugs", "Politics", "Porn", "Religion & Belief", "Toxic", "Violence", "Vulgarity", and "War & Conflict". Default: false.

Troubleshooting

If you encounter issues with code snippets or setup, refer to the Troubleshooting Guide.

HTTP method and URL:

POST https://LOCATION-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/LOCATION/publishers/google/models/imagegeneration@006:predict

Request JSON body:

{
  "instances": [
    {
      "prompt": "TEXT_PROMPT"
    }
  ],
  "parameters": {
    "sampleCount": IMAGE_COUNT,
    "safetySetting": "SAFETY_SETTING",
    "personGeneration": "PERSON_SETTING",
    "includeRaiReason": INCLUDE_RAI_REASON,
    "includeSafetyAttributes": INCLUDE_SAFETY_ATTRIBUTES
  }
}

To send your request, choose one of these options:

Note: The following command assumes that you have logged in to the gcloud CLI with your user account by running gcloud init or gcloud auth login, or by using Cloud Shell, which automatically logs you into the gcloud CLI. You can check the currently active account by running gcloud auth list.

Save the request body in a file named request.json, and execute the following command:

curl -X POST \
     -H "Authorization: Bearer $(gcloud auth print-access-token)" \
     -H "Content-Type: application/json; charset=utf-8" \
     -d @request.json \
     "https://LOCATION-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/LOCATION/publishers/google/models/imagegeneration@006:predict"

Note: The following command assumes that you have logged in to the gcloud CLI with your user account by running gcloud init or gcloud auth login. You can check the currently active account by running gcloud auth list.

Save the request body in a file named request.json, and execute the following command:

$cred = gcloud auth print-access-token
$headers = @{ "Authorization" = "Bearer $cred" }

Invoke-WebRequest `
    -Method POST `
    -Headers $headers `
    -ContentType: "application/json; charset=utf-8" `
    -InFile request.json `
    -Uri "https://LOCATION-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/LOCATION/publishers/google/models/imagegeneration@006:predict" | Select-Object -Expand Content

The response you receive depends on the safety settings you configure. For more information, see Understand and configure Responsible AI (RAI) for Imagen.
