    Prompt and image attribute guide¶

    To use Imagen on Vertex AI, you provide a text description, or prompt, of the image you want to generate or edit. Prompts are the primary way you communicate your intent to the generative model.

    This guide explains how to structure prompts to achieve different results and provides examples of images you can create. It also covers how to refine your prompts through iteration to achieve your desired outcome.

    Before you begin¶

    Concepts
    • Prompt: A natural language text description provided to a generative model to request a specific output, such as generating an image.
    • Negative Prompt: A supplemental prompt that specifies what you want to exclude from the generated image.
    • Imagen: A family of text-to-image diffusion models developed by Google that generate photorealistic images from input text.
    • Parameterization: The process of creating a prompt template with variables that can be dynamically populated, often used in applications to control user inputs.
    • Aspect Ratio: The proportional relationship between the width and height of an image.

    Product usage¶

    To view usage standards and content restrictions associated with Imagen on Vertex AI, see the usage guidelines.

    Content filtering¶

    Generated images are filtered for undesirable or harmful content. Similarly, any input Imagen on Vertex AI receives is checked for offensive content, including text prompts and uploaded photos for image editing. For more information, see Responsible AI and usage guidelines for Imagen.

    You can also report suspected abuse of Imagen on Vertex AI or any generated output that contains inappropriate material or inaccurate information using the Report suspected abuse on Google Cloud form.

    Prompting basics¶

    While there's no single correct way to write a prompt, a descriptive and clear prompt is more likely to produce the desired result. A good starting point is to structure your prompt around three key elements: subject, context, and style.

    • Subject: The main object, person, animal, or scenery you want in the image.
    • Context and background: The environment or setting where the subject is placed, such as a studio with a white background, an outdoor landscape, or an indoor scene.
    • Style: The artistic look of the image. Styles can be general (e.g., painting, photograph, sketch) or specific (e.g., pastel painting, charcoal drawing, isometric 3D).

    After writing an initial prompt, refine it by adding more details. Iteration is key. Start with a core idea and expand upon it until the generated image aligns with your vision.

    Advanced prompting techniques¶

    To create more specific images, you can add advanced attributes and modifiers to your prompt.

    Photography modifiers¶

    Use photography-specific keywords to control camera properties, lighting, and film effects.

    Specify the distance between the camera and the subject.

    Define the camera's angle relative to the subject.

    Describe the lighting conditions to set the mood.

    Simulate camera settings to achieve effects like motion or focus.

    Specify lens types for different perspectives and focal effects.

    Reference film types for classic photographic styles.

    Illustration and art styles¶

    You can generate images in a wide range of artistic styles, from simple sketches to complex digital art or historical movements.

    The following images were generated with the prompt "An [art style] of an angular sporty electric sedan with skyscrapers in the background" using the Imagen 2 model.

    The following images were generated with the prompt "generate an image in the style of [art period or movement]: a wind farm" using the Imagen 3 model.

    Shapes and materials¶

    Create imaginative imagery by combining subjects with unusual materials or shapes.

    Image quality modifiers¶

    Add keywords to signal that you are looking for a high-quality image.

    • General Modifiers: high-quality, beautiful, stylized
    • Photos: 4K, HDR, Studio Photo
    • Art/Illustration: by a professional, detailed

    Aspect ratios¶

    Imagen 3 lets you set five distinct image aspect ratios.

    • Square (1:1, default): A standard square photo, common for social media posts.
    • Fullscreen (4:3): Commonly used in media, film, and medium format cameras.
    • Portrait full screen (3:4): The fullscreen ratio rotated 90 degrees, capturing more vertical detail.
    • Widescreen (16:9): The standard for modern TVs, monitors, and landscape mobile photos.
    • Portrait (9:16): Widescreen rotated 90 degrees, ideal for tall subjects like skyscrapers or waterfalls.

    Negative prompts¶

    A negative prompt is a powerful tool that specifies what elements to omit from an image. Simply describe what you don't want to see.

    • Recommended: Plainly describe what to exclude (e.g., wall, frame).
    • Not Recommended: Avoid instructive language like "no" or "don't" (e.g., no walls, don't show walls).

    Model-specific guidance: Imagen 3¶

    View Imagen 3 for Generation model card

    Imagen 3 can transform ideas into detailed images from both short and long prompts. Refine your vision through iterative prompting, adding details until you achieve the perfect result.

    Additional advice for Imagen 3 prompt writing:

    • Use descriptive language: Employ detailed adjectives and adverbs to paint a clear picture for Imagen 3.
    • Provide context: If necessary, include background information to aid the AI's understanding.
    • Reference specific artists or styles: If you have a particular aesthetic in mind, referencing specific artists or art movements can be helpful.
    • Enhance facial details: To improve facial details in personal and group images, specify it as a focus (e.g., use the word "portrait") and consider using the larger Imagen 3 model instead of Imagen 3 Fast.

    Troubleshooting

    If you encounter issues with code snippets or setup, refer to the Troubleshooting Guide.

    Generate text in images¶

    Imagen 3 can add text to your images. Use the following guidance to get the most out of this feature:

    • Iterate with confidence: You might have to regenerate images multiple times to achieve the look you want.
    • Keep it short: Limit text to 25 characters or less for optimal generation.
    • Use multiple phrases: Experiment with two or three distinct phrases. Avoid exceeding three phrases for cleaner compositions.
    • Guide placement: While Imagen can attempt to position text as directed, expect occasional variations.
    • Inspire font style: Specify a general font style (e.g., bold font) to influence Imagen's choices.
    • Influence font size: Specify a font size or a general indication of size (e.g., small, medium, large).

    Programmatic prompting with parameterization¶

    When using the Imagen API or Vertex AI SDK for Python, you can parameterize prompts to better control output. This is useful for applications where you want to limit user choices or ensure consistent output styles.

    For example, to let customers generate logos for their businesses on a solid color background, you can create a parameterized prompt template:

    A {logo_style} logo for a {company_area} company on a solid color background. Include the text {company_name}.

    In your application, the user can select values for {logo_style}, {company_area}, and {company_name} from a menu, which then populate the prompt sent to Imagen.

    Example 1: * Prompt: A minimalist logo for a health care company on a solid color background. Include the text Journey.

    Example 2: * Prompt: A modern logo for a software company on a solid color background. Include the text Silo.

    Example 3: * Prompt: A traditional logo for a baking company on a solid color background. Include the text Seed.
