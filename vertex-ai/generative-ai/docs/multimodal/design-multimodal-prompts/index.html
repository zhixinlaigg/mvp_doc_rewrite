Design multimodal prompts¶

The Gemini API lets you send multimodal prompts to the model. The supported modalities include text, image, and video. A multimodal prompt can include a mix of these, such as an image and a text question about the image.

For general prompt design guidance, see Prompt design strategies.

Concepts
  • Multimodal prompt: A prompt that includes more than one type of media, such as a combination of text and images.
  • Few-shot learning: A technique where you provide a few examples in your prompt to guide the model to produce a response in a similar format or style.
  • Temperature: A parameter that controls the randomness of the model's output; lower values result in more predictable responses, while higher values yield more creative ones.
  • Top-K: A parameter that limits the model's selection of the next token to the K most likely tokens.
  • Top-P: A parameter that limits the model's selection of the next token to a cumulative probability threshold P.

Troubleshooting

If you encounter issues, refer to the Vertex AI Troubleshooting Guide.

Prompt design fundamentals¶

This section provides best practices and examples for designing effective multimodal prompts. Note that model results can vary between runs.

Be specific in your instructions

Prompts are most successful when they are clear and detailed. If you have a specific output in mind, include that requirement in the prompt. Vague instructions can lead to generic responses, so craft your prompt to minimize misinterpretation.

View an example of adding specificity

To get a specific output, ensure your instructions are detailed. For example, instead of a generic request, ask the model to parse specific information from an image.

Original prompt

A generic prompt leads to a general description.

Describe this image.

Response

The image shows an airport arrivals and departures board.

Improved prompt

A specific prompt guides the model to extract the exact data you need.

Parse the time and city from the airport board shown in this image into a list.

Response

  • 10:50 Moscow
  • 11:05 Edinburgh
  • 11:05 London
  • 11:10 Bucharest
  • 11:30 Kiev
  • 11:35 Dublin
  • 11:45 East Midlands
  • 12:15 Sofia
  • 12:30 London
  • 12:30 Newcastle
  • 12:40 St Petersburg
  • 12:40 London
  • 12:45 Manchester

Provide few-shot examples

The Gemini model can accept multiple inputs to use as examples, a technique called "few-shot learning." Adding examples helps the model identify patterns and apply the relationship between the given inputs and responses to your new request.

View a few-shot learning example

If the initial output isn't in the desired format, you can provide examples to guide the model.

Original prompt

The initial response is a full sentence and includes the country.

Determine the city along with the landmark.

Response

The landmark is the Christ the Redeemer statue in Rio de Janeiro, Brazil.

Improved prompt with few-shot examples

By providing examples, you can steer the model to produce output in a specific key: value format and exclude the country.

Determine the city along with the landmark.

city: Rome, landmark: the Colosseum.

city: Beijing, landmark: Forbidden City

Response

city: Rio de Janeiro, landmark: Christ the Redeemer statue

Break down complex tasks

For tasks that require complex reasoning, it can be helpful to split the task into smaller, more straightforward steps in your prompt. Alternatively, you can ask the model to "think step-by-step."

View an example of breaking down a task

For complex problems, guiding the model step-by-step or asking it to think sequentially can significantly improve the accuracy of the response.

Original prompt

What is the 4th term in the sequence?

Response

-135

This response is incorrect. To improve it, you can ask the model to parse the problem first.

Improved prompt (parsing first)

Parse the formula in the image first. Then based on the formula, answer "what's the 4th term in the sequence?".

Response

$$ b(n) = b(n-1) * (-3) $$ $$ b(1) = 15 $$

  1. Substitute n = 4 into the formula: $$ b(4) = b(4-1) * (-3) $$ $$ b(4) = b(3) * (-3) $$

  2. We don't know the value of b(3), so substitute n = 3 into the formula: $$ b(3) = b(3-1) * (-3) $$ $$ b(3) = b(2) * (-3) $$

  3. We don't know the value of b(2), so substitute n = 2 into the formula: $$ b(2) = b(2-1) * (-3) $$ $$ b(2) = b(1) * (-3) $$

  4. We know the value of b(1) is 15, so substitute it into the formula: $$ b(2) = 15 * (-3) $$ $$ b(2) = -45 $$

  5. Now that we know the value of b(2), substitute it into the formula for b(3): $$ b(3) = b(2) * (-3) $$ $$ b(3) = -45 * (-3) $$ $$ b(3) = 135 $$

  6. Now that we know the value of b(3), substitute it into the formula for b(4): $$ b(4) = b(3) * (-3) $$ $$ b(4) = 135 * (-3) $$ $$ b(4) = -405 $$

Therefore, the 4th term in the sequence is -405.

Improved prompt (streamlined)

To get a more concise and correct answer, ask the model to think step-by-step.

What is the 4th term in the sequence? Think step by step.

Response

The first term is 15. The second term is b(1) * (-3) = 15 * (-3) = -45. The third term is b(2) * (-3) = -45 * (-3) = 135. The fourth term is b(3) * (-3) = 135 * (-3) = -405.

Specify the output format

If you need the model's output in a specific format like Markdown, JSON, or HTML, instruct the model to do so in the prompt. This is especially useful if the output is for a downstream task.

View examples of specifying output format

Example 1: Requesting Markdown

Prompt

Parse the table in this image into markdown format.

Response 

| Subject   | Status      | Time    | Start date | Due on     |
| --------- | ----------- | ------- | ---------- | ---------- |
| Math      | Done        | 1.5 hrs | 11/29/2023 | 12/1/2023  |
| Geography | Done        | 30 min  | 12/2/2023  | 12/4/2023  |
| Physics   | In progress | 2 hrs   | 12/3/2023  | 12/5/2023  |
| Biology   | Not started | 6 hrs   | 11/2/2016  | 12/6/2023  |

Example 2: Requesting JSON

Prompt

Provide a list of all the following attributes: ingredients, type of cuisine, vegetarian or not, in JSON format.

Response 

{
  "ingredients": [
    "rice",
    "shrimp",
    "clams",
    "mussels",
    "peas",
    "tomatoes",
    "onions",
    "garlic",
    "olive oil",
    "paprika",
    "salt",
    "pepper"
  ],
  "type of cuisine": "Spanish",
  "vegetarian": false
}

Place media before text for single-image prompts

While Gemini can handle image and text inputs in any order, placing the image or video before the text prompt might improve performance for prompts containing a single piece of media. For prompts where images and text are highly interleaved, use the order that is most natural.

Troubleshooting your prompts¶

If you aren't getting a helpful response, try these troubleshooting strategies.

Add hints for the model

If the model isn't drawing information from the relevant part of an image, add hints to your prompt to guide its focus.

View an example of adding hints

By providing more context and directing the model to use specific information from the image, you can get a more accurate and reasoned response.

Original prompt

How many days will these diapers last a baby?

Response

The diapers will last for 198 days before they run out.

Improved prompt

How long will these diapers last before I run out? Use the weight shown on the box to determine the child's age, and use the total number of diapers in the box. Divide the total number by how many diapers the child goes through per day.

Response

The box contains 198 diapers. The box states the diapers are for a child weighing 22-37 lbs. The average child in this weight range is likely between 1 and 2 years old. A 2-year-old typically goes through 6 diapers per day, therefore, the diapers will last around 33 days (198/6).

Ask the model to describe the media first

If the model's output is too generic, ask it to first describe the image or video before providing the task instruction. This can help the model tailor its response to the specifics of the media. You can also explicitly ask the model to refer to what's in the image.

View an example of asking for a description first

To get a more insightful response about a collection of images, ask the model to describe each one first.

Original prompt

What is in common between these images?

Response

All four images are examples of landscape photography.

Improved prompt

First, describe what's in each image in detail. What's in common between these images?

Response

The first image shows a person packing a suitcase. The second image shows an empty hallway in a shopping mall. The third image shows a roll of toilet paper. The fourth image shows a dark and stormy sea. The commonality between these images is that they are all examples of liminal spaces. Liminal spaces are places or situations that are in between two other places or situations. They are often characterized by a sense of uncertainty or ambiguity. The first image shows the person in between being at home and being on a trip. The second image shows the hallway in between two stores. The third image is of toilet paper, which can represent a bathroom. A bathroom is a transitional space between private and public realms. It's a place where we prepare ourselves to enter or leave the outside world. The fourth image shows the sea in between being calm and being stormy. Liminal spaces can be both exciting and unsettling. They can be a place of new beginning or a place of endings. They can be a place of reflection or a place of action.

Debug by isolating the failure point

It can be hard to know if a prompt failed because the model didn't understand the image or because it failed to perform the correct reasoning steps. To find the root cause, ask the model to describe the image or explain its reasoning.

View an example of isolating the failure

If a model's suggestion seems odd, you can troubleshoot by asking it to first describe the image to ensure it understood the context correctly.

Original prompt

What's a snack I can make in 1 minute that would go well with this?

If the model suggests something unusual, like popcorn, you can check its understanding.

Troubleshooting prompt

To check if the model correctly identified the image:

Describe what's in this image.

To check the model's reasoning:

What's a snack I can make in 1 minute that would go well with this? Please explain why.

Tune sampling parameters to control creativity

In each request, you send a set of sampling parameters to the model. The model can generate different results for different parameter values. Experiment with these parameters to get the best values for your task.

Parameter Description
Temperature Controls the degree of randomness in the output. Lower values (e.g., 0.2) are more deterministic, while higher values (e.g., 0.8) are more creative.
Top-K Limits the model's selection to the K most likely next tokens. A lower value narrows the choices, making the output less random.
Top-P Limits the model's selection to a cumulative probability, selecting from the most likely tokens until the sum of their probabilities reaches the Top-P value.

Temperature

Temperature is used for sampling during response generation. It controls the degree of randomness in token selection. Lower temperatures are good for prompts that require a more deterministic response, while higher temperatures can lead to more diverse or creative results. A temperature of 0 is deterministic. For most use cases, start with a temperature of 0.4.

Top-K

Top-K changes how the model selects tokens for output. A top-K of 1 means the next selected token is the most probable among all tokens in the model's vocabulary (greedy decoding). A top-K of 3 means that the next token is selected from among the three most probable tokens using temperature. Specify a lower value for less random responses and a higher value for more random responses.

Top-P

Top-P changes how the model selects tokens for output. Tokens are selected from most to least probable until the sum of their probabilities equals the top-P value. For example, if tokens A, B, and C have a probability of 0.6, 0.3, and 0.1 and the top-P value is 0.9, then the model will select either A or B as the next token by using temperature and excludes C as a candidate. Specify a lower value for less random responses and a higher value for more random responses.
