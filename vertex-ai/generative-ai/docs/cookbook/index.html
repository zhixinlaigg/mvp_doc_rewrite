Generative AI on Vertex AI Cookbook¶

This cookbook provides a collection of guides and examples to help you get started with Generative AI on Vertex AI.

Explore more in the Generative AI Repository on GitHub.

Concepts
  • Gemini: A family of multimodal models developed by Google that can understand and process information from text, images, audio, and video.
  • Function Calling: A feature that allows models to connect to external tools and APIs to retrieve real-time information or perform actions.
  • Grounding: The process of connecting a model's responses to verifiable sources of information, like Google Search or private data, to improve accuracy and reduce hallucinations.
  • RAG (Retrieval-Augmented Generation): An architecture that enhances LLM responses by first retrieving relevant information from an external knowledge base and providing it to the model as context.
  • Imagen: A family of text-to-image models for generating and editing photorealistic images.
  • Orchestration: The process of coordinating multiple components, such as different models, tools, and data sources, to build complex AI applications and workflows.

Troubleshooting

If you encounter issues with the code in these notebooks, refer to the Vertex AI Troubleshooting Guide.
