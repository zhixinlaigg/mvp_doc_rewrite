    Execute code with the Gemini API¶

    The Gemini API code execution feature enables the model to generate and run Python code and learn iteratively from the results until it arrives at a final output. You can use this code execution capability to build applications that benefit from code-based reasoning and that produce text output. For example, you could use code execution in an application that solves equations or processes text.

    The Gemini API provides code execution as a tool, similar to function calling. After you add code execution as a tool in your request, the model decides when to use it.

    Supported models and limitations¶

    The following models support the code execution feature:

    Preview

    • Gemini 1.5 Flash-Lite
    • Gemini 1.5 Pro-Lite
    • Gemini 1.5 Pro
    • Gemini 1.5 Flash
    • Gemini 1.0 Pro

    Limitations¶

    • The feature doesn't support file I/O.
    • Code execution can run for a maximum of 60 seconds before timing out.

    How to use code execution¶

    To use code execution, include the code_execution tool in the tools property of your request. The following examples show how to send a prompt that requires calculation and text processing.

    PROJECT_ID="myproject"
REGION="us-central1"
MODEL_ID="gemini-1.5-flash-001"

curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  "https://${REGION}-aiplatform.googleapis.com/v1/projects/${PROJECT_ID}/locations/${REGION}/publishers/google/models/${MODEL_ID}:generateContent" \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [{
        "text": "Calculate 20th fibonacci number. Then find the nearest palindrome to it."
      }]
    }],
    "tools": [{"code_execution": {}}],
  }'

    import vertexai
from vertexai.generative_models import GenerativeModel, Tool

# TODO(developer): Update and un-comment below lines
# project_id = "my-project"
# location = "us-central1"
# vertexai.init(project=project_id, location=location)

model = GenerativeModel(
    "gemini-1.5-flash-001",
    tools=[Tool.from_google_search_retrieval(grounding_config=None)],
)

code_execution_tool = Tool.from_dict(
    {"code_execution": {}}
)

response = model.generate_content(
    "Calculate 20th fibonacci number. Then find the nearest palindrome to it.",
    tools=[code_execution_tool],
)

for part in response.candidates[0].content.parts:
    if part.executable_code:
        print(part.executable_code)
    if part.code_execution_result:
        print(part.code_execution_result)

# Example response:
# code='print(fib(20))' language=PYTHON
# outcome: OK
# output: "6765\n"
#
# code: '...' language=PYTHON
# outcome: OK
# output: "Lower Palindrome: 6666\nHigher Palindrome: 6776\nNearest Palindrome to 6765: 6776\n"

    Troubleshooting

    If you encounter issues with code snippets or setup, refer to the Troubleshooting Guide.

    Code execution reference¶

    To use code execution, you include a Tool object in your request. The model then responds with Part objects containing executable code or the results of that execution.

    Tool object

    To enable code execution, include a Tool object in your request where the code_execution field is set to an empty object ({}).

    Part object

    When the model decides to use the code execution tool, the response from the API contains a Part object. This object will contain one of the following fields:

    • executable_code: An ExecutableCode object containing the code generated by the model that is meant to be executed by the tool.
    • code_execution_result: A CodeExecutionResult object containing the result of executing the code.

    ExecutableCode object

    This object contains the code generated by the model to be executed.

    Field Description
    language Required. The programming language of the generated code. Currently, only PYTHON is supported.
    code Required. The code to be executed.

    CodeExecutionResult object

    This object contains the result of a code execution.

    | Field | Description -| **Required**. The outcome of the code execution. Possible values include:<ul><li>OUTCOME_OK: Code executed successfully.</li><li>OUTCOME_FAILED: Code execution finished with a failure. Theoutputfield should contain the reason.</li><li>OUTCOME_DEADLINE_EXCEEDED: Code execution timed out and was canceled. A partial output might be present.</li></ul> | |output| **Required**. Containsstdoutfrom the execution if successful, orstderr` or another error description if it failed. - |
