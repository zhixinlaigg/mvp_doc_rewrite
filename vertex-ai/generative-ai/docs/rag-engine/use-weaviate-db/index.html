Use a Weaviate database with Vertex AI RAG Engine¶

Preview

Some of the RAG features are Preview offerings, subject to the "Pre-GA Offerings Terms" of the Google Cloud Service Specific Terms. Pre-GA products and features may have limited support, and changes to Pre-GA products and features may not be compatible with other Pre-GA versions. For more information, see the launch stage descriptions.

Further, by using the Gemini API on Vertex AI, you agree to the Generative AI Preview terms and conditions (Preview Terms).

The VPC-SC security controls and CMEK are supported by Vertex AI RAG Engine. Data residency and AXT security controls aren't supported.

This page shows you how to connect your RAG Engine corpus to your Weaviate database. You can use your Weaviate database instance, which is an open-source database, with RAG Engine to index and conduct a vector-based similarity search.

To see an example of using RAG Engine with Weaviate, you can also follow along with the "RAG Engine with Weaviate" Jupyter notebook in one of the following environments:

Open in Colab Open in Colab Enterprise Open in Vertex AI Workbench View on GitHub

A similarity search finds pieces of text that are similar to your query, which requires the use of an embedding model. The embedding model produces vector data for each piece of text being compared. The similarity search is used to retrieve semantic contexts for grounding to return the most accurate content from your LLM.

With RAG Engine, you can continue to use your fully-managed vector database instance, which you are responsible for provisioning. RAG Engine uses the vector database for storage, index management, and search.

Before you begin¶

Expand to see all prerequisites
Concepts
  • RAG (Retrieval-Augmented Generation): A method that enhances LLM responses by retrieving relevant information from an external knowledge base.
  • Vector Database: A database designed to store and query high-dimensional vectors, commonly used for similarity searches.
  • Embedding Model: A model that converts text or other data into numerical vector representations (embeddings).
  • Secret Manager: A Google Cloud service for securely storing and managing secrets like API keys, passwords, and certificates.
  • Hybrid Search: A search technique that combines keyword-based (sparse vector) and semantic (dense vector) search methods to improve result relevance.

1. Set up your Weaviate database

Before using the Weaviate database with RAG Engine, you must provision your Weaviate instance.

  • Create and deploy your Weaviate database instance and collection. You can follow the Weaviate official quickstart guide or optionally use the Google Cloud Marketplace guide. You are responsible for managing your Weaviate database instance lifecycle.
  • Prepare an HTTPS endpoint. While HTTP is supported, an HTTPS connection between RAG Engine and your Weaviate database is recommended.

  • Create a Weaviate collection with the required schema. RAG Engine requires a one-to-one mapping between a RAG corpus and a Weaviate collection. Use the following schema when creating your collection:

    Property name Data type
    fileId text
    corpusId text
    chunkId text
    chunkDataType text
    chunkData text
    fileOriginalUri text

  • Create a Weaviate API key. RAG Engine uses an API key for authentication and authorization. Follow the Weaviate authentication guide to configure API key-based authentication.

2. Set up your Google Cloud project

  1. Sign in to your Google Cloud account. If you're new to Google Cloud, create an account to evaluate how our products perform in real-world scenarios. New customers also get $300 in free credits to run, test, and deploy workloads.

  2. In the Google Cloud console, on the project selector page, select or create a Google Cloud project.

    Note

Cloud Shell is a shell environment with the Google Cloud CLI already installed and with values already set for your current project. It can take a few seconds for the session to initialize.

3. Store your Weaviate API key in Secret Manager

To protect your API key, store it in Secret Manager and grant the RAG Engine service account access to it.

  1. Store your Weaviate API key in Google Cloud Secret Manager.
  2. Grant your project's RAG Engine service account permissions to access the secret. The service account is created automatically when you create your first RAG resource and has the format service-{project-number}@gcp-sa-vertex-rag.iam.gserviceaccount.com.
    1. Navigate to your project's IAM & Admin page.
    2. Enable the option Include Google-provided role grants.
    3. Find the service account and grant it the Secret Manager Secret Accessor (roles/secretmanager.secretAccessor) role.

# Import the Secret Manager client library.
from google.cloud import secretmanager
from typing import Optional
import google_crc32c  # type: ignore


def create_secret(
    project_id: str, secret_id: str
) -> secretmanager.Secret:
    """
    Create a new secret with the given name.
    """
    client = secretmanager.SecretManagerServiceClient()
    parent = f"projects/{project_id}"
    response = client.create_secret(
        request={
            "parent": parent,
            "secret_id": secret_id,
            "secret": {"replication": {"automatic": {}}},
        }
    )
    print(f"Created secret: {response.name}")
    return response

def add_secret_version(
    project_id: str, secret_id: str, payload: str
) -> secretmanager.SecretVersion:
    """
    Add a new secret version to the given secret with the provided payload.
    """
    client = secretmanager.SecretManagerServiceClient()
    parent = client.secret_path(project_id, secret_id)
    payload_bytes = payload.encode("UTF-8")
    crc32c = google_crc32c.Checksum()
    crc32c.update(payload_bytes)
    response = client.add_secret_version(
        request={
            "parent": parent,
            "payload": {
                "data": payload_bytes,
                "data_crc32c": int(crc32c.hexdigest(), 16),
            },
        }
    )
    print(f"Added secret version: {response.name}")
    return response

Step 2: Create a RAG corpus¶

Expand to see corpus creation steps and code

Create a RAG corpus and set the Weaviate instance as its vector database. When calling the CreateRagCorpus or UpdateRagCorpus APIs, you must specify the Weaviate configuration.

  • rag_vector_db_config.weaviate: Contains all Weaviate configuration fields.
  • weaviate.http_endpoint: The Weaviate endpoint. This is immutable once set.
  • weaviate.collection_name: The name of your Weaviate collection. This is immutable once set.
  • api_auth.api_key_config.api_key_secret_version: The resource name of the secret version in Secret Manager containing your Weaviate API key. This is mutable.

First-time corpus creation

If you are creating a RAG corpus for the first time in a project, the RAG Engine service account might not exist yet.

  1. Create a RAG corpus with an empty Weaviate configuration to trigger the creation of the service account (service-{project-number}@gcp-sa-vertex-rag.iam.gserviceaccount.com).
  2. Grant this new service account the Secret Manager Secret Accessor role as described in the "Before you begin" section.
  3. Call the UpdateRagCorpus API to update the corpus with your Weaviate endpoint, collection name, and API key secret version.

Subsequent corpus creation

If the service account already exists, you can create the RAG corpus with the full Weaviate configuration in a single CreateRagCorpus API call.

Use hybrid search

Hybrid search, which combines semantic (dense vector) and keyword (sparse vector) searches, is supported with a Weaviate database to improve the relevance of search results. You can enable it by setting the retrieval_strategy during a retrieval query. You can also adjust the weight between dense and sparse vector similarity.

from vertexai import rag
import vertexai

# TODO(developer): Update and un-comment below lines
# PROJECT_ID = "your-project-id"
# corpus_name = "projects/[PROJECT_ID]/locations/us-central1/ragCorpora/[rag_corpus_id]"

# Initialize Vertex AI API once per session
vertexai.init(project=PROJECT_ID, location="us-central1")

response = rag.retrieval_query(
    rag_resources=[
        rag.RagResource(
            rag_corpus=corpus_name,
        )
    ],
    text="Why is the sky blue?",
    retrieval_strategy="hybrid", # Enable hybrid search
    hybrid_alpha=0.75, # Optional: weight for dense vectors (0.0 to 1.0)
)
print(response)
