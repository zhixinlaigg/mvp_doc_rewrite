    Supervised tuning Gemini models¶

    You can use supervised tuning to improve the performance of a Gemini model for your specific tasks. Supervised tuning uses a dataset of labeled examples that demonstrate the type of output you want from the model. Supervised tuning is a full tuning method, which means it updates all of the model's weights during tuning.

    Supported models¶

    The following Gemini models support supervised tuning:

    • gemini-1.0-pro-002

    Workflow for supervised tuning a model¶

    The workflow for supervised model tuning includes the following steps:

    1. Prepare your model tuning dataset.
    2. Upload the model tuning dataset to a Cloud Storage bucket.
    3. Create a supervised model tuning job.
    4. View and load your tuned model for inference.

    Before you begin

    Complete the following steps before you start the tuning process.

    1. Set up your project

      1. Sign in to your Google Cloud account. If you're new to Google Cloud, create an account to evaluate how our products perform in real-world scenarios. New customers also get $300 in free credits to run, test, and deploy workloads.
      2. In the Google Cloud console, on the project selector page, select or create a Google Cloud project.
      3. Make sure that billing is enabled for your Cloud project.
      4. Enable the Vertex AI API.
      5. Install and initialize the gcloud CLI.

    2. Authorize the gcloud CLI

      To authorize the gcloud CLI to use your Google Account credentials to access Google Cloud services and APIs, run the following command:

      gcloud auth application-default login

    3. Set project and location variables

      Set environment variables for your project ID and location. The location can be any of the supported regions for Gemini models.

      export PROJECT_ID="your-project-id"
export LOCATION="us-central1"

gcloud config set project $PROJECT_ID
gcloud config set location $LOCATION

    Prepare your supervised tuning dataset¶

    The dataset for supervised tuning must be in a JSON Lines (JSONL) format, where each line contains a single tuning example with input_text and output_text fields. The input_text field contains the prompt, and the output_text field contains the ideal response.

    The maximum length for input_text is 8,192 tokens, and for output_text is 8,192 tokens. The combined length of input_text and output_text cannot exceed 9,216 tokens.

    Example dataset:

    {"input_text": "question: How many people live in the USA?", "output_text": "answer: The USA has a population of 331.9 million people."}
{"input_text": "question: What is the capital of France?", "output_text": "answer: The capital of France is Paris."}

    Dataset recommendations:

    • Size: We recommend a dataset with 100 to 500 examples for successful tuning. The minimum number of examples required is 10.
    • Quality: The quality of the data is more important than the quantity. Ensure your dataset contains high-quality, diverse examples that reflect the real-world scenarios for which you are tuning the model.

    Your dataset must be uploaded to a Cloud Storage bucket. For more information, see Upload the dataset to Cloud Storage.

    Upload the dataset to Cloud Storage¶

    To run a tuning job, you need to upload your dataset to a Cloud Storage bucket.

    1. Create a Cloud Storage bucket

      If you don't have one already, create a Cloud Storage bucket in the same project and region where you plan to tune your model.

      export BUCKET="your-bucket-name"
export REGION="us-central1"

gsutil mb -l $REGION gs://$BUCKET

    2. Upload the dataset to your bucket

      Run the following command to upload your dataset file to the Cloud Storage bucket.

      gsutil cp your-dataset.jsonl gs://$BUCKET/

    Choose a method to tune your model¶

    You can tune a model using the Google Cloud console, the REST API, or the Vertex AI SDK for Python. Choose the method that best suits your workflow and technical expertise.

    Method Best for Pros Cons
    Google Cloud console Quick experimentation and users who prefer a graphical interface. - Visual interface for creating and monitoring jobs.
    - No coding required.    		 - Less suitable for automation or integration into CI/CD pipelines.
    - Manual process for each tuning job.
    REST API Integrating tuning into custom applications or automated workflows where the Vertex AI SDK is not available. - Language-agnostic.
    - Full programmatic control.    		 - Requires manual construction of HTTP requests and handling responses.
    - More complex than using the SDK.
    Vertex AI SDK for Python Users working in a Python environment, especially in notebooks or scripts. - Simplifies API interaction with a high-level, intuitive interface.
    - Easily integrates with other Python data science libraries.    		 - Requires a Python environment and installation of the SDK.

    Create a model tuning job¶

    You can create a supervised model tuning job using the Google Cloud console, the API, or the Vertex AI SDK for Python.

    Troubleshooting

    If you encounter issues with code snippets or setup, refer to the Troubleshooting Guide.

    1. In the Google Cloud console, go to the Tune & Distill page in the Vertex AI section.

      Go to Tune & Distill

    2. Click Create tuned model to open the tuning pane.

    3. In the Base model dropdown, select gemini-1.0-pro-002.
    4. Enter a name for your tuned model and, optionally, a description.
    5. In Training data, specify the Cloud Storage path to your JSONL dataset file (e.g., gs://your-bucket-name/your-dataset.jsonl).
    6. Adjust the Training steps. The number of steps depends on your dataset size and learning rate. We recommend starting with 100 steps.
    7. Adjust the Learning rate. We recommend a value between 0.0001 and 0.001.
    8. Click Start tuning to begin the model tuning job. The job can take several hours to complete, depending on the dataset size and number of training steps.

    To create a tuning job using the REST API, send a POST request to the pipelineJobs endpoint.

    In your request, specify the following:

    • displayName: A name for your tuning job.
    • base_model: The name of the model you want to tune (gemini-1.0-pro-002).
    • dataset_uri: The Cloud Storage path to your dataset.
    • tuned_model_display_name: A name for your tuned model.
    • train_steps: The number of training steps.
    • learning_rate: The learning rate for tuning.
    curl -X POST \
-H "Authorization: Bearer $(gcloud auth print-access-token)" \
-H "Content-Type: application/json" \
"https://us-central1-aiplatform.googleapis.com/v1/projects/${PROJECT_ID}/locations/${LOCATION}/pipelineJobs?pipelineJobId=gemini-tuning-$(date +%Y%m%d%H%M%S)" \
-d '{
  "displayName": "gemini-supervised-tuning-job",
  "runtimeConfig": {
    "gcsOutputDirectory": "gs://'${BUCKET}'/tuning-output",
    "parameterValues": {
      "project": "'${PROJECT_ID}'",
      "location": "'${LOCATION}'",
      "base_model": "gemini-1.0-pro-002",
      "dataset_uri": "gs://'${BUCKET}'/your-dataset.jsonl",
      "tuned_model_display_name": "my-tuned-gemini-model",
      "train_steps": 100,
      "learning_rate": 0.0002
    }
  },
  "templateUri": "https://us-kfp.pkg.dev/ml-pipeline/large-language-model-pipelines/tune-gemini/v1.0.0"
}'

    To create a tuning job using the Vertex AI SDK for Python, you first need to install the SDK:

    pip install --upgrade google-cloud-aiplatform

    Then, use the following Python script to start the tuning job.

    import google.cloud.aiplatform as aiplatform

# Initialize the Vertex AI SDK
aiplatform.init(project="your-project-id", location="us-central1")

# Define the tuning job
job = aiplatform.PipelineJob(
    display_name="gemini-supervised-tuning-job",
    template_path="https://us-kfp.pkg.dev/ml-pipeline/large-language-model-pipelines/tune-gemini/v1.0.0",
    pipeline_root="gs://your-bucket-name/tuning-output",
    parameter_values={
        "project": "your-project-id",
        "location": "us-central1",
        "base_model": "gemini-1.0-pro-002",
        "dataset_uri": "gs://your-bucket-name/your-dataset.jsonl",
        "tuned_model_display_name": "my-tuned-gemini-model",
        "train_steps": 100,
        "learning_rate": 0.0002,
    },
)

# Run the job
job.run()

    View a list of your tuned models¶

    After the tuning job is complete, you can view your tuned model in the Google Cloud console, or list it programmatically using the API or SDK.

    1. In the Google Cloud console, go to the Vertex AI Model Registry page.

      Go to Model Registry

    2. Your tuned model will be listed with the name you provided (e.g., my-tuned-gemini-model).

    To list your tuned models, send a GET request to the models endpoint.

    curl -X GET \
-H "Authorization: Bearer $(gcloud auth print-access-token)" \
"https://us-central1-aiplatform.googleapis.com/v1/projects/${PROJECT_ID}/locations/${LOCATION}/models"

    Use the list method of the Model class to get a list of your models.

    import google.cloud.aiplatform as aiplatform

# Initialize the Vertex AI SDK
aiplatform.init(project="your-project-id", location="us-central1")

# List all models
models = aiplatform.Model.list()
for model in models:
    print(f"Model ID: {model.name}, Display Name: {model.display_name}")

    Load a tuned model¶

    Once your model is tuned, you can load it to get predictions.

    1. Go to the Vertex AI Model Registry page and select your tuned model.
    2. Click Deploy to create an endpoint for your model.
    3. Once the endpoint is created, you can use the Test your model interface to send prompts and get responses.

    To get predictions from your tuned model, you first need to find its endpoint ID. You can find this in the Google Cloud console or by listing endpoints via the API. Then, send a POST request to the predict method of that endpoint.

    export ENDPOINT_ID="your-endpoint-id"
export INPUT_TEXT="question: What is the weather like in London?"

curl -X POST \
-H "Authorization: Bearer $(gcloud auth print-access-token)" \
-H "Content-Type: application/json" \
"https://us-central1-aiplatform.googleapis.com/v1/projects/${PROJECT_ID}/locations/${LOCATION}/endpoints/${ENDPOINT_ID}:predict" \
-d '{
  "instances": [
    { "prompt": "'"$INPUT_TEXT"'" }
  ]
}'

    Use the GenerativeModel class from the Vertex AI SDK to load your tuned model and send prompts.

    from vertexai.generative_models import GenerativeModel

# The `tuned_model_name` can be found in the Model Registry
# It will be in the format: projects/PROJECT_ID/locations/LOCATION/models/MODEL_ID
tuned_model_name = "your-tuned-model-name"

model = GenerativeModel(tuned_model_name)

response = model.generate_content("question: What is the weather like in London?")
print(response.text)

    Tuning job metrics¶

    You can view tuning job metrics in Cloud Logging. The two metrics available are model/loss and model/learning_rate, which represent the loss and learning rate for each training step.

    To view the logs: 1. Go to the Logs Explorer in the Google Cloud console. 2. In the Query field, enter resource.type="aiplatform.googleapis.com/PipelineJob". 3. Filter by your pipelineJob ID to find the relevant logs.

    Troubleshooting¶

    Troubleshooting common issues

    Region Mismatch Error

    • Issue: You might encounter an INVALID_ARGUMENT error if the Cloud Storage bucket for your dataset is in a different region than your model tuning job.
    • Solution: Ensure that your tuning job is running in the same region as the Cloud Storage bucket containing your dataset.

    Permission Denied Error

    • Issue: You might get a permission error if the service account for the tuning job does not have the necessary permissions to access the dataset in Cloud Storage.
    • Solution: Grant the Storage Object Viewer role (roles/storage.objectViewer) to the service account running the pipeline job.
