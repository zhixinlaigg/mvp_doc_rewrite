Batch predictions with Anthropic Claude models¶

Batch predictions let you send a large number of non-latency-sensitive prompts to an Anthropic Claude model in a single request. This is more efficient than online predictions, where you send only one prompt per request.

Before you begin¶

Before you begin
Concepts
  • Batch Prediction: A process for sending a large number of model inference requests in a single asynchronous job.
  • JSONL (JSON Lines): A text format where each line is a separate, valid JSON object, used for streaming structured data.
  • BigQuery: A fully managed, serverless data warehouse for storing and querying large datasets.
  • Cloud Storage: A scalable and durable object storage service for unstructured data like files.
  • REST API: A standardized way for systems to communicate over HTTP, allowing you to interact with Google Cloud services programmatically.

Supported models and quotas¶

Vertex AI supports batch predictions for the following Anthropic Claude models:

  • Claude Opus 4
  • Claude Sonnet 4
  • Claude 3.7 Sonnet
  • Claude 3.5 Sonnet v2
  • Claude 3.5 Haiku

By default, you can make up to four concurrent batch requests in a single project.

Prepare your input data¶

Your input dataset must be in a BigQuery table or a JSONL file in Cloud Storage. The following table compares the two input sources.

Feature BigQuery Cloud Storage
Format A table with specific columns. A JSONL file where each line is a request object.
Use Case Ideal for structured data already in BigQuery. Best for unstructured or file-based data.
Location The BigQuery table must be in the same region as the batch prediction job. The Cloud Storage bucket can be in any region, but co-locating it with the job can improve performance.

Input data format

For both BigQuery and Cloud Storage, each input request must follow the Anthropic Claude API Schema in JSON format.

{
  "custom_id": "request-1",
  "request":  {
    "messages": [{"role": "user", "content": "Hello!"}],
    "anthropic_version": "vertex-2023-10-16",
    "max_tokens": 50
  }
}

BigQuery requirements

Your BigQuery input table must have the following columns. Any other columns are ignored.

Column name Description
custom_id A unique ID for each request to match inputs with outputs.
request The request body, which contains your prompt and parameters.

Note

Batch prediction jobs reserve response(JSON) and status for the output. Do not use these as column names in your input table.

Cloud Storage requirements

For Cloud Storage, the input must be a JSONL file located in a Cloud Storage bucket. Each line in the file must be a JSON object representing a single prediction request.

Step 1: Request a batch prediction

You can request a batch prediction job using either the Vertex AI SDK for Python or the REST API. You can use input from either BigQuery or Cloud Storage and write the output to either destination, regardless of the input source.

To learn how to install or update the Vertex AI SDK for Python, see Install the Vertex AI SDK for Python. For more information, see the Vertex AI SDK for Python API reference documentation.

Troubleshooting

If you encounter issues with code snippets or setup, refer to the Troubleshooting Guide.

import time

from google import genai
from google.genai.types import CreateBatchJobConfig, JobState, HttpOptions

client = genai.Client(http_options=HttpOptions(api_version="v1"))

# TODO(developer): Update and un-comment one of the following sections.

# Option 1: Use BigQuery for input and output
# The source dataset needs to be created specifically in us-east5
# input_uri = "bq://python-docs-samples-tests.anthropic_bq_sample.test_data"
# output_uri = f"bq://your-project.your_dataset.your_table"

# Option 2: Use Cloud Storage for input and output
# Source link: https://storage.cloud.google.com/cloud-samples-data/batch/anthropic-test-data-gcs.jsonl
input_uri = "gs://cloud-samples-data/anthropic-test-data-gcs.jsonl"
output_uri = "gs://your-bucket/your-prefix"

# See the documentation: https://googleapis.github.io/python-genai/genai.html#genai.batches.Batches.create
job = client.batches.create(
    # Check Anthropic Claude region availability in https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude#regions
    # More about Anthropic model: https://console.cloud.google.com/vertex-ai/publishers/anthropic/model-garden/claude-3-5-haiku
    model="publishers/anthropic/models/claude-3-5-haiku",
    src=input_uri,
    config=CreateBatchJobConfig(dest=output_uri),
)
print(f"Job name: {job.name}")
print(f"Job state: {job.state}")
# Example response:
# Job name: projects/%PROJECT_ID%/locations/us-central1/batchPredictionJobs/9876453210000000000
# Job state: JOB_STATE_PENDING

# The following code polls for job completion.
# See the documentation: https://googleapis.github.io/python-genai/genai.html#genai.types.BatchJob
completed_states = {
    JobState.JOB_STATE_SUCCEEDED,
    JobState.JOB_STATE_FAILED,
    JobState.JOB_STATE_CANCELLED,
    JobState.JOB_STATE_PAUSED,
}

while job.state not in completed_states:
    time.sleep(30)
    job = client.batches.get(name=job.name)
    print(f"Job state: {job.state}")
# Example response:
# Job state: JOB_STATE_PENDING
# Job state: JOB_STATE_RUNNING
# ...
# Job state: JOB_STATE_SUCCEEDED

Before using any of the request data, make the following replacements:

  • LOCATION: A region that supports the selected Anthropic Claude model (see Claude Regions).
  • PROJECT_ID: Your project ID.
  • MODEL: The name of the model (e.g., claude-3-5-haiku).
  • INPUT_URI: The BigQuery table (bq://...) or Cloud Storage URI (gs://...) of your input data.
  • OUTPUT_FORMAT: bigquery or jsonl.
  • DESTINATION: bigqueryDestination or gcsDestination.
  • OUTPUT_URI_FIELD_NAME: outputUri for BigQuery or outputUriPrefix for Cloud Storage.
  • OUTPUT_URI: The destination BigQuery table (bq://...) or Cloud Storage prefix (gs://...).

HTTP method and URL

POST https://LOCATION-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/LOCATION/batchPredictionJobs

Request body for BigQuery input

'{
  "displayName": "JOB_NAME",
  "model": "publishers/anthropic/models/MODEL",
  "inputConfig": {
    "instancesFormat":"bigquery",
    "bigquerySource":{
      "inputUri" : "INPUT_URI"
    }
  },
  "outputConfig": {
    "predictionsFormat":"OUTPUT_FORMAT",
    "DESTINATION":{
      "OUTPUT_URI_FIELD_NAME": "OUTPUT_URI"
    }
  }
}'

Request body for Cloud Storage input

'{
  "displayName": "JOB_NAME",
  "model": "publishers/anthropic/models/MODEL",
  "inputConfig": {
    "instancesFormat":"jsonl",
    "gcsSource":{
      "uris" : ["INPUT_URI"]
    }
  },
  "outputConfig": {
    "predictionsFormat":"OUTPUT_FORMAT",
    "DESTINATION":{
      "OUTPUT_URI_FIELD_NAME": "OUTPUT_URI"
    }
  }
}'

To send your request, save one of the request bodies to a file named request.json and choose one of the following options.

Step 2: Get the status of a batch prediction job

After you submit a batch prediction job, you can check its status to see if it has completed.

The Python code in the previous step includes a while loop that polls the job status until it reaches a completed state (JOB_STATE_SUCCEEDED, JOB_STATE_FAILED, etc.). You can use the client.batches.get() method to retrieve the current status of a job at any time.

# client is an initialized genai.Client
# job_name is the full resource name of the job from the create step
job = client.batches.get(name=job_name)
print(f"Job state: {job.state}")

Before using any of the request data, make the following replacements:

  • PROJECT_ID: Your project ID.
  • LOCATION: The region where your batch job is located.
  • JOB_ID: The batch job ID that was returned when you created the job.

HTTP method and URL

GET https://LOCATION-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/LOCATION/batchPredictionJobs/JOB_ID

To send your request, choose one of the following options.

Step 3: Retrieve batch prediction output

When your batch prediction job is complete, the output is saved to the destination you specified.

  • BigQuery: The output is added to your destination BigQuery table. A new column named response(JSON) contains the prediction result for each corresponding input row.
  • Cloud Storage: The output is saved as one or more JSONL files in the specified output bucket and folder. Each file contains the prediction results.

You can access the full batch prediction results after all rows have completed or after 24 hours, whichever comes first.
