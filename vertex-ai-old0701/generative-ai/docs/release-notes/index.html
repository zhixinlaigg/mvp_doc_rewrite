Vertex AI release notes¶

This page documents production updates to Vertex AI. You can check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality.

You can find the latest product updates for all of Google Cloud in several ways: * Visit the main Google Cloud release notes page. * Browse and filter all release notes in the Google Cloud console. * Programmatically access release notes in BigQuery.

To get the latest product updates delivered to you, add the URL of this page to your feed reader, or add the feed URL directly.

June 30, 2025¶

Vertex AI Agent Engine

Vertex AI Agent Engine Memory Bank is now available in Preview. Memory Bank lets you dynamically generate long-term memories based on users' conversations with your agent.

June 27, 2025¶

Multimodal Datasets

Multimodal datasets are now available in Preview. For more information, see Multimodal datasets.

June 24, 2025¶

Deprecation of Imagen 1, Imagen 2, and Vision Models

Starting on June 24, 2025, Imagen versions 1 and 2, image captioning, and visual question answering are deprecated.

On September 24, 2025, the following features and models will be removed:

  • image captioning
  • visual question answering
  • Imagen 1 model imagegeneration@002
  • Imagen 2 models imagegeneration@005 and imagegeneration@006

For more information, see Migrate to Imagen 3.

June 23, 2025¶

Veo 2

Support for advanced video controls in Veo 2 is now Generally Available (GA). In addition to providing a first frame of a video, you can specify the last frame of a video or a video to extend in length. For more information, see Veo on Vertex AI API.

June 17, 2025¶

Gemini 2.5 Flash and Gemini 2.5 Pro

Gemini 2.5 Flash and Gemini 2.5 Pro are now Generally Available (GA) and accessible through the API and Vertex AI Studio. For more information, see Gemini 2.5 Flash and Gemini 2.5 Pro.

Gemini 2.5 Flash-Lite

Gemini 2.5 Flash-Lite is now available in Preview in both the API and Vertex AI Studio. For more information, see Gemini 2.5 Flash-Lite.

Live API

The Live API is now available as a private General Availability (GA) offering in the API and Vertex AI Studio. To request access, contact your Google account team representative. For more information, see Live API.

Gemini 2.5 preview endpoint migration

The following updates apply to the migration from preview to GA endpoints for Gemini 2.5 models:

  • Endpoint availability and removal: All existing Gemini 2.5 Flash and Pro preview endpoints will remain available at preview pricing until July 15, 2025. After this date, the following preview endpoints will be shut down:
    • gemini-2.5-flash-preview-04-17
    • gemini-2.5-flash-preview-05-20
    • gemini-2.5-pro-preview-03-25
    • gemini-2.5-pro-preview-05-06
    • gemini-2.5-pro-preview-06-05
  • Updated pricing for Gemini 2.5 Flash GA: The GA price for Gemini 2.5 Flash is adjusted to reflect its quality and unified output token pricing, including lower prices for thinking output and higher prices for non-thinking output. These changes take effect on the new GA endpoint. Preview pricing continues on existing preview endpoints until July 15, 2025.
  • Provisioned Throughput (PT): All new PT purchases for GA models will be for GA endpoints only. If you have purchased PT for a preview version, you must migrate the existing PT to the GA endpoint or purchase new PT for the GA endpoint by July 15, 2025.
  • Updated preview endpoints: Effective June 19, 2025, the gemini-2.5-flash-preview-04-17 endpoint serves the Gemini 2.5 Flash model version released on 05-20 (promoted to GA). Similarly, the gemini-2.5-pro-preview-05-06 and 03-25 endpoints serve the Gemini 2.5 Pro model version released on 06-05 (promoted to GA). This ensures continuity during your transition.

February 07, 2025¶

Model Garden

deepseek-ai/deepseek-r1 and microsoft/Phi-4 models were added to Model Garden.

The following advanced LLM inference optimization techniques are available in Model Garden in Preview:

  • Prefix caching reuses computations from previously generated text, eliminating redundant processing. It reduces time-to-first-token for requests with common prompt prefixes. Prefix caching is available for the following models:
    • vLLM: Llama 3.1 (8b, 70b), Llama 3.3 (70b)
    • Hex-LLM: Llama 2 (7b, 13b), Llama 3 (8b), Llama 3.1 (8b, 70b), Llama 3.2 (1b, 3b), Llama Guard (1b, 8b), CodeLlama (7b, 13b), Gemma (2b, 7b), CodeGemma (2b, 7b), Mistral-7B (v0.2, v0.3), Mixtral-8x7B (v0.1)
  • Speculative decoding is an effective optimization technique to reduce generation time-per-output-token latency. For more information, see the Model Garden advanced features notebook.
