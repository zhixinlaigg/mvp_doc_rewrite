    Cost of building and deploying AI models in Vertex AI¶

    This document details the pricing for Generative AI services on Vertex AI. Prices are listed in US Dollars (USD). If you pay in a currency other than USD, the prices listed in your currency on Cloud Platform SKUs apply.

    You are charged only for requests that return a 200 OK response code. Requests that result in other response codes, such as 4xx or 5xx, do not incur charges for input or output.

    For all other Vertex AI pricing, including ML Platform and MLOps services, see the Vertex AI pricing page.

    Model Availability

    Starting April 29, 2025, Gemini 1.5 Pro and Gemini 1.5 Flash models are not available in projects that have no prior usage of these models, including new projects. For details, see Model versions and lifecycle.

    Concepts
    • Token: The basic unit of text processed by a large language model; approximately 4 characters of English text equals one token.
    • Grounded Prompt: A request submitted to a model that includes one or more queries to an external data source like Google Search to provide more factual and up-to-date responses.
    • Provisioned Throughput: A service that provides a reserved amount of model processing capacity for a fixed price, ensuring consistent performance and throughput.
    • Generative AI Scale Unit (GSU): The unit of measure for purchasing provisioned throughput.
    • Context Caching: A feature that stores parts of your input (context) to reduce costs and latency on subsequent requests with similar context.

    Grounding¶

    Grounding enhances model responses by connecting them to external data sources. Gemini model usage fees apply separately.

    • Grounding with Google Search:

      • Gemini 2.0 Flash, 2.5 Flash, and 2.5 Flash-Lite: Includes a combined 1,500 grounded prompts per day at no additional charge.
      • Gemini 2.5 Pro: Includes 10,000 grounded prompts per day at no additional charge.
      • Overage: Prompts exceeding the daily free limit are billed at $35 per 1,000 grounded prompts.
      • Billing: Charged only when a prompt successfully returns web results.

    • Web Grounding for enterprise:

      • Price: $45 per 1,000 grounded prompts.
      • Billing: Charged only when a prompt successfully returns web results.

    • Grounding with your data:

      • Price: $2.50 per 1,000 requests (starting June 16, 2025).

    For usage exceeding 1 million grounded prompts per day, please contact your account team.

    Vertex AI Model Optimizer¶

    Experimental

    Model Optimizer is a paid experimental offering and may route requests to experimental versions of Gemini on Vertex.

    Vertex AI Model Optimizer simplifies model selection by automatically routing your query to the best-fit Gemini model (Flash, Pro, etc.) based on your preference for cost, quality, or a balance of both. It uses dynamic pricing, where the cost per token depends on the model used. The tables below show pricing examples for common scenarios.

    Example cost calculation¶

    A user needs to support 10 queries per second (QPS) for a query with 1,000 input text tokens, 500 input audio tokens, and 300 output text tokens using gemini-2.0-flash.

    1. Calculate Burndown-Adjusted Tokens per Query: Using the throughput and burndown rate table, we find the rates for gemini-2.0-flash:

      • Input text burndown rate: 1 token
      • Input audio burndown rate: 7 tokens

      • Output text burndown rate: 4 tokens

      • Input tokens: (1,000 text tokens * 1) + (500 audio tokens * 7) = 4,500 burndown-adjusted tokens

      • Output tokens: 300 text tokens * 4 = 1,200 burndown-adjusted tokens
      • Total per query: 4,500 + 1,200 = 5,700 total tokens

    2. Calculate Total Tokens per Second:

      • 5,700 tokens/query * 10 QPS = 57,000 total tokens per second.

    3. Calculate Required GSUs:

      • 57,000 tokens/sec ÷ 3,360 per-second throughput/GSU = 16.96 GSUs.
      • Since the minimum purchase increment is 1, the user needs 17 GSUs.

    4. Calculate Cost:

      • 1 week: 17 GSUs * $1,200/GSU = $20,400
      • 1 month: 17 GSUs * $2,700/GSU = $45,900
      • 3 months: 17 GSUs * $2,400/GSU = $40,800 per month
      • 1 year: 17 GSUs * $2,000/GSU = $34,000 per month
